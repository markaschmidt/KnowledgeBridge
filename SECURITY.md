# Reporting issues

Do not post private note text, credentials, real vault paths or Rhen source in public issues. Report a minimal synthetic reproduction. For a suspected access-control vulnerability, use the repository's private vulnerability reporting channel if enabled rather than a public issue.

This is a development preview. The integration limits its own tools; it does not sandbox the editor, an agent's terminal or other extensions. Model clients may retain returned content. See `docs/ARCHITECTURE.md` and `docs/RHEN.md` for the boundaries and current limitations.
